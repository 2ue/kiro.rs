此外，`.vscode/settings.json` 含共享构建目录路径，按“保留本机共享 target”要求未改；worktree 的 `.git` 是包含原工作区路径的普通指针文件，`--exclude-dir=.git` 无法排除它。这两项也会被任务的原始扫描命中。

原命令的 `--exclude-dir=docs/claude-pool-refactor`、`--exclude-dir=scripts/refactor` 与 `--exclude=.cargo/config.toml` 在当前 grep 中不能按预期排除这些相对路径，应改用能匹配路径的过滤方式。用于定位范围外残留的命令为：

```bash
rg -n -i --hidden --no-ignore 'kiro' . \
  -g '!.git' -g '!.git/**' -g '!target/**' -g '!**/node_modules/**' \
  -g '!docs/claude-pool-refactor/**' -g '!scripts/refactor/**' \
  -g '!.cargo/config.toml' -g '!src/migration/**'
```

达到全仓零残留需要在文档层明确这些范围外文件的处理方式，尤其是旧迁移夹具的归属/豁免和项目技能的去留；本轮没有擅自迁移测试、删减兼容证据或改写技能设计。设计目录入口据此标记“范围内完成、全仓验收未通过”，未按要求写成无条件“已完成”。
