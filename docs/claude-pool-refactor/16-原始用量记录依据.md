## 三模式统一双用量字段增量

新增 `upstream_last_max_cost`。三种模式统一保存 rawUsage 与 rawCostUsage，分别为最大/最大、最终/最终、最终/最大。成本统一以 rawCostUsage 为输入；旧 JSON 在反序列化边界将缺失的 rawCostUsage 视为 rawUsage。UI 三选一并始终展示两个字段。默认保持 legacy_max；账号倍率、usage 整形及可计费值保持原处理链。DB 增加旧两值 CHECK 到三值 CHECK 的迁移和兼容性守卫；旧记录不回填。
