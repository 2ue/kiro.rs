# kiro.rs 项目问题审计与整改方案（2026-10-16）

状态：基于 `main@317a8b1`（v0.0.194，已部署到 59137）的现状审计
范围：全仓源码、运维与 CI、线上 59137 只读巡检、语言跟随问题
不在范围：`feat/console-ui`、`feature/account-runtime-upstream-accounts` 两个未合入分支

## 结论

v0.0.194 已修复热路径阻塞、自愈惊群、Redis 集合无界增长和 prompt cache 锁热点四类问题，上线后 2 小时成功率 97.41% → 98.55%，p95 85.3s → 51.8s。剩余问题按优先级：

1. **语言跟随（P1，用户诉求）**：长 agent 会话中工具调用之间的进度说明漂成英文。根因已定位，方案已确定，是下一版本的唯一任务。
2. **可靠性与可观测性（P2）**：准入限流仅进程内、刷新协议两套并存、回落靠错误文案匹配、部署时连同 PG/Redis 重启。
3. **工程质量（P2/P3）**：9 个长期失败测试、release 流水线不跑全量、万行文件、重复定义、两套前端、仓库卫生。
