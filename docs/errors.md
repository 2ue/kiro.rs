# 错误说明

接口出错时返回 Anthropic 兼容的错误结构：

```json
{
  "type": "error",
  "error": {
    "type": "api_error",
    "message": "本次请求处理失败，请稍后重试。The request failed to complete. Please retry.（请求编号 request id: req_01...）"
  },
  "request_id": "req_01..."
}
```

- `message` 先给中文说明，再给英文说明，末尾的「请求编号」只用于排查，反馈问题时附上即可。
- 只要本次请求失败，HTTP 状态码就不会是 200，失败的请求不计费。
- 唯一的例外：流式响应已经开始输出内容之后才中断。此时状态码已经是 200，错误会以流里的 `event: error` 事件结束；这类请求在中断前确实收到过内容。

响应头 `x-should-retry: false` 表示原样重试不会成功，需要先调整请求。

## 错误一览

| 状态码 | type | 文案（中文部分） | 原因 | 调用方怎么做 |
|---|---|---|---|---|
| 502（可调整为 503 / 529） | api_error（529 时为 overloaded_error） | 模型这次没有返回任何内容，已自动重试仍未成功，请重试本轮对话。 | 模型返回成功但整条回复没有任何文字、思考或工具调用；服务端已自动换线路重试 | 直接重试本轮；频繁出现时稍等再试 |
| 502 | api_error | 本次请求处理失败，请稍后重试。 | 请求已发出但没有正常完成 | 稍后重试 |
| 503 / 504 / 529 | api_error / overloaded_error | 模型服务暂时没有响应，请稍后重试。 | 网络超时、连接中断或服务繁忙 | 稍后重试 |
| 200（流内 error 事件） | overloaded_error | 回复在输出过程中中断，请重试本轮对话。 | 已经输出部分内容后连接中断 | 重试本轮；客户端（如 Claude Code）通常会自动重试 |
| 429 | rate_limit_error | 当前请求较多，请稍后重试。 / 当前请求较多，请 N 秒后重试。 | 请求频率过高或处理容量暂时用满 | 按提示的秒数后重试 |
| 503 | api_error | 服务正在准备中，暂时无法处理请求，请稍后重试。 | 服务刚启动或正在切换 | 稍后重试 |
| 400 | invalid_request_error | 请求内容无法被模型接受，常见原因是历史消息、工具调用结果或附件格式有误。请精简内容或新开对话后重试。 | 请求结构不被接受 | 检查历史消息与工具结果，或新开对话；原样重试不会成功 |
| 400 | invalid_request_error | `prompt is too long: ...` | 输入超过长度上限 | 压缩上下文（如 `/compact`）或新开对话。此文案保持英文，Claude Code 依赖它自动压缩 |
| 400 | invalid_request_error | 有图片超过 5 MB 的大小上限，请压缩或移除后重试。 | 单张图片过大 | 压缩或移除图片 |
| 400 | invalid_request_error | 本次请求携带的图片超过 100 张的上限，请新开对话或减少截图后重试。 | 图片数量过多 | 新开对话或减少截图 |
| 400 | invalid_request_error | 有图片的格式无法识别，请转换为 PNG、JPEG、GIF 或 WebP 后重试。 | 图片格式不支持 | 转换格式后重试 |
| 400 | invalid_request_error | 模型给出的原因说明（原文） | 参数不被所选模型支持，例如要求特定的 thinking 设置 | 按说明调整参数 |
| 404 | not_found_error | 请求的模型不存在或不可用 | 模型名错误 | 更换模型 |
| 400 | invalid_request_error | 请求的模型在当前接口不可用，请更换模型。 | 该接口不提供这个模型 | 更换模型 |
| 502 | api_error | 联网搜索没有成功，请稍后重试，或关闭联网搜索后再试。 | 联网搜索工具失败 | 稍后重试或关闭联网搜索 |

## 空回说明

「空回」只按整条回复判断：回复结束时从头到尾都没有任何文字、思考或工具调用才算。回复过程中某一段暂时没有内容、长时间思考后才开始输出，都不算空回，会正常返回。

空回时服务端会先自动换线路重试，全部失败后才返回上面第一行的错误，不计费。
