# 01 现状诊断

## 1. 两套前端

| | `admin-ui/`（旧） | `ui/`（现行） |
|---|---|---|
| 挂载 | `/admin` | `/ui` |
| 栈 | React 18 / Tailwind 3 / Vite 5 | React 18 / Tailwind 4 / react-router 6 / recharts 3 |
| 导航 | 单页 `activeTab`，URL 不变（`admin-ui/src/components/dashboard.tsx:211`） | 11 个路由，按页 lazy（`ui/src/app/router.tsx:55-87`） |
| 代码量 | 约 2.47 万行 | 约 2.65 万行 |

`ui/` 覆盖了 `admin-ui/` 的全部功能，另外还有凭据诊断、外部池风控、routeKind 筛选和版本展示。两边都没有用上的后端能力包括：`POST /credentials/import`（目前批量导入是在前端逐条 POST）、`/credentials-paged`、聚合版 `/usage-dashboard`、`supported-models/sync`、`PATCH /credentials/{id}/auth`。

## 2. 问题清单（按影响排序）

### P0：数据安全与一致性

1. **外部池策略有两个编辑入口，会互相覆盖。** `runtime-page.tsx:879-1361` 和 `external-pools-page.tsx:375-630` 编辑的是同一批 `externalPools*` 字段，两边保存时都 PUT 完整的 RuntimeConfig。外部池页保存后会刷新 `runtime-config`，这时运行页会用新数据整份覆盖草稿（`runtime-page.tsx:463-515`），未保存的修改就静默丢了。整个仓库里也没有离开页面时的保护（`beforeunload` / `useBlocker`）。
2. **危险操作不需要确认。** 卡片上的启用开关点一下就直接禁用账号（`credential-card.tsx:455-465`）。
3. **Admin Key 以明文存在 localStorage**（`ui/src/lib/storage.ts`），与 refactor-plan 07 的约定冲突。

### P1：信息架构

4. **同一个操作有多个入口。** 负载均衡模式 2 处，查询积分 4 处，删除已禁用账号 3 处，同步价格 2 处。"验活"和"系统账号复查"功能相近，但名称和调用的接口都不一样。
5. **导航按数据对象划分，不按任务划分。** 处理外部池问题要在"外部池""外部池风控""用量""总览·费用""运行·路由策略"五个地方来回跳。运行页的分类 key 叫 `externalPools`，显示的标题却是"路由策略"（`runtime-page.tsx:97`）。
6. **运行配置是一张巨型表单。** 共 207 个数值或开关字段，一次平铺展示，没有标出哪些是常用项，也看不出哪些值改过默认值。

### P1：状态表达

7. 状态 badge 直接显示 `disabledReason` 的原始枚举，比如 `TooManyRefreshFailures`（`credential-card.tsx:411`），而且不能按禁用原因筛选。
8. 判断调度状态时没有考虑 `disabled`，所以已禁用的账号会显示成"可调度"（`credential-utils.ts:93-107`）。
9. 同一种状态在不同位置颜色不一样：冷却在一处是 warning，在另一处是 error，而且同一张卡上冷却信息出现了三次。

### P2：性能与体验

10. 账号列表默认展开。每张卡片挂了约 20 个 query/mutation hook 和 8 个弹窗（`credential-card.tsx:172-191, 796-1154`），每页 15 张卡。
11. 轮询频率高，用户也控制不了。账号页同时有 5 秒、10 秒、30 秒、60 秒多组定时器（`use-credentials.ts:82-178`），关闭自动刷新后总览面板仍然每 5 秒刷新一次（`overview-page.tsx:256`）。
12. 用量表最小宽度 1280px，只有上一页/下一页两种翻页方式，详情要弹窗查看，看完列表的上下文就丢了。
13. 审计页的筛选只作用于当前页，因为后端只支持 page/limit 参数，筛选结果会让人误以为是全部数据。
14. 移动端：卡片摘要固定 `grid-cols-6`，没有做断点适配。

### P2：工程一致性

15. 业务层用了 16 处原生 `<button>`；有 36 处硬编码色板类、84 处任意字号；手写分页 3 处；`NumField`、`maskSecret` 等工具函数各有 2 到 3 份重复实现。
16. 多个单文件超过 1200 行，最大的是 `types/api.ts`，2162 行；其次是 `runtime-page.tsx`，1885 行。
