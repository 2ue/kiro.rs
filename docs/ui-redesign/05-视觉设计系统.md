# 05 视觉设计系统

风格方向：类似 Linear、Vercel 的克制型运维控制台。中性灰底，配一个品牌色，信息密度较高，暗色主题优先打磨。不使用渐变大卡片和装饰性插画。

## 1. 色彩

全部定义为 CSS 变量，使用 oklch，在 Tailwind v4 中通过 `@theme inline` 映射。业务代码里禁止直接使用 `text-red-500` 这类色板类。

| Token | 用途 |
|---|---|
| `--background / --surface-1/2/3` | 页面、卡片、悬浮层三级表面 |
| `--border / --border-strong` | 分隔线、聚焦描边 |
| `--foreground / --muted-foreground` | 主文本、次文本 |
| `--primary` | 品牌色，暂定 Kiro 紫 `oklch(0.62 0.19 293)`，只用于主按钮、选中项和焦点 |
| `--success / --warning / --danger / --info` | 语义色，各配 `-subtle` 底色和 `-foreground` |
| `--chart-1…8` | 图表分类色，需要通过亮色和暗色两套对比度校验 |

## 2. 状态语义（全局唯一映射）

| 状态 | 颜色 | 图标 | 附加信息 |
|---|---|---|---|
| 可调度 Healthy | success | `CircleCheck` | 无 |
| 在用 Busy | info | `Activity` | 在途数 / 并发 |
| 冷却 Cooling | warning | `Timer` | 倒计时 |
| 限流 RateLimited | warning | `Gauge` | 恢复时间 |
| 观察期 Probation | info（描边） | `Eye` | 剩余时间 |
| 异常 Failing | danger | `TriangleAlert` | 最近错误类型 |
| 已禁用 Disabled | 中性灰 | `CircleSlash` | 原因（中文） |
| 未知 Unknown | 中性灰（虚线） | `CircleHelp` | "未查询" |

一个对象只显示一个主状态。主状态按以下优先级确定：禁用 > 异常 > 限流 > 冷却 > 观察期 > 在用 > 可调度。次要状态在 hover 卡片里展示。这套映射由 `domain/credential-status.ts` 统一产出，组件不各自判断。

## 3. 额度进度条

| 使用率 | 颜色 |
|---|---|
| < 50% | success |
| 50% ~ 80% | warning |
| 80% ~ 100% | 橙色（danger 的 70% 色阶） |
| > 100%（超额） | danger 加斜纹溢出段 |

进度条右侧显示"重置于 Nd"，快照过期时显示为半透明，并加时钟图标。

## 4. 排版与密度

- 字体：系统字体栈 `Inter, "PingFang SC", system-ui`；数字使用 `tabular-nums`，ID 和 Key 使用 `JetBrains Mono` / `ui-monospace`。
- 字号阶梯（只用这几档，不再使用任意值）：12 / 13 / 14 / 16 / 20 / 24。
- 密度提供两档：紧凑（行高 32px，默认）和舒适（40px），作为全局设置。
- 间距使用 4px 栅格，卡片圆角 8px，弹层 12px。
- 数字列右对齐，单位用次要色、缩小一号显示。

## 5. 图表规范

- 统一使用 Recharts，并通过 shadcn Chart 封装 `ChartContainer` 和主题。
- 同一页面的图表共享时间轴和 tooltip 格式。
- 错误一律用 danger 色，其他分类按 `--chart-n` 的顺序固定分配，同一个模型在不同图表里颜色一致（按 key 做 hash 映射）。
- 空数据时显示 `DataState`，不画空坐标轴。
- 图表下方提供"查看数据"表格切换，满足无障碍要求。

## 6. 动效与无障碍

- 只在 Sheet 和 Dialog 进出、数值变化闪烁这两处使用动效（150 到 200ms），并遵守 `prefers-reduced-motion`。
- 颜色不作为唯一信息载体：状态同时配图标和文字。
- 所有交互组件来自 Radix，保证键盘可达；焦点环使用 `--ring`。
- 文本对比度目标 ≥ 4.5:1。完整的 WCAG 合规需要用辅助技术做人工测试。
