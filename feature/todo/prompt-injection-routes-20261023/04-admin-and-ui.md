# 04 管理接口与页面

## 1. 管理接口

| 接口 | 作用 |
|---|---|
| `GET /api/admin/prompt-injection/catalog` | 返回 03 第 4 节的目录：每个注入项的说明、默认文本（含各变体）、可编辑性、依赖、建议、关闭后的影响；同时返回"拆出去的功能"的说明。页面上的说明文字全部来自这里 |
| `GET/PUT /api/admin/config/runtime` | 已有接口，增加 `promptInjection`、`routeFeatures`、`claudeModelsOnly` 三个字段，删掉 `promptSteering` 和 `promptSteeringDefaults`。保存时执行 02 第 1 节的文本校验 |
| `POST /api/admin/prompt-injection/preview` | 入参：路由、上游（本地 / 外部池）、模型、是否带 system、是否带 Write/Edit、tool_choice、thinking 类型、是否模拟空轮重试，以及一份可选的未保存配置草稿。后端用这些条件构造合成请求，调用真实的注入和 `convert_request`，返回每一项的结果（注入 / 不注入及原因 / 注入位置 / 最终文本），以及发给 Kiro 的 `history[0]`、当前轮 user 消息和 tools 描述的完整内容 |

预览接口不访问上游，也不写缓存、usage 或任何状态。传入配置草稿时只在本次调用里使用，不会保存。

## 2. 页面结构（只改 `ui/`）

### 2.1 新页面"提示词注入"

在侧栏中和"路由策略"同级，分四个 Tab。

1. **注入项**：按 01 的分类分组，每项一张卡片，内容包括：
   - 名称、分类、位置、触发条件、依赖。
   - 全局默认开关；支持外部池的项再加一个"外部池"开关。
   - 建议等级徽标。"建议开"的项关闭时显示红色提示，提示内容是"关闭后的影响"。
   - 注入文本：可编辑的项用 `Textarea`，旁边有"恢复默认"按钮，改过的显示"已修改"标记，并能查看和默认文本的差异；只读的项用代码块展示所有变体，并说明为什么只读。
   - 顶部提供批量操作："全部默认值设为关"和"全部恢复新装默认"，执行前用 `Dialog` 确认。
2. **路由矩阵**：行是路由，列是注入项，单元格显示生效值，并区分"显式开 / 显式关 / 跟随默认"。点单元格打开该路由的编辑弹窗，并定位到"提示词注入"分区。
3. **不可关闭的内容**：C 类、D2–D4、F1，只展示文本和"为什么不能关"。
4. **预览**：表单填写第 1 节的入参，结果按"注入项结果表"加"发给 Kiro 的完整文本"两栏展示。默认使用当前页面上还没保存的草稿，所以可以先预览再保存。

### 2.2 路由策略编辑弹窗

现在的弹窗是"缓存策略 + 身份 + WebSearch"一路往下排。改为用 `Tabs` 分成三个分区：

| 分区 | 内容 |
|---|---|
| 缓存 | 现有的 `PathStrategyBindingCard`，内容不变 |
| 提示词注入 | 14 个注入项，每项一个 `Select`：跟随默认（当前开/关）/ 开启 / 关闭；支持外部池的项多一个外部池 `Select`。每项下面一行显示文本前 80 个字符和"在提示词注入页编辑"链接。依赖不满足的项显示"不生效：原因" |
| 功能 | `-thinking` 模型名解析、thinking 触发方式、渠道信息输出过滤（含"流式也过滤"）、WebSearch 模型驱动 |

- 原来的 `route-identity-editor.tsx` 和 `route-websearch-editor.tsx` 合并进这两个新分区，旧文件删除。
- 路由卡片上的徽标改为三组：缓存策略名、"注入 N 项"、开启的功能。
- 复制和导入导出路由策略（`route-policy-transfer.ts`）要带上三个分区。导出格式升一个版本号，旧格式导入时把身份和 WebSearch 字段按迁移规则转换。

### 2.3 运行配置页

- 删除"提示词引导"和"身份与渠道隐藏"两个区块，原位置改成一行说明加跳转链接。
- "协议转换"里的"结构化 tool_choice"说明改为"只控制工具过滤和响应侧拦截，提示词见提示词注入页"。删除"thinking 转换能力"和"分块工具策略"两个开关。
- "模型"分区增加"模型列表只显示 Claude"开关。

### 2.4 旧版 admin-ui

`/admin` 仍然在提供服务，它的运行配置页会读写 `promptSteering`。处理方式：

- 删除 admin-ui 里提示词和身份相关的所有编辑区块，改成"请在新版管理后台编辑"的提示。
- 保存载荷里不再带 `promptSteering`。后端对这个字段直接拒绝，返回 400，提示改用新字段，避免旧页面悄悄写入。

## 3. 前端实现约定

- 组件统一用 `@/components/ui`：`Tabs`、`Select`、`Switch`、`Textarea`、`Dialog`、`Badge`、`Tooltip`。
- 新类型写进 `ui/src/types/api.ts`，并通过 `scripts/check-frontend-contracts.mjs` 的类型对齐检查。
- 页面上不再硬编码任何默认文本或"关闭影响"说明，全部从 catalog 接口取。
